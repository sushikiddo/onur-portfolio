# Onur Can Orhan — Portfolyo

Canlı site: https://onurcanorhan.pages.dev/

Türkçe ve İngilizce çok sayfalı statik portfolyo. Kömür proje sayfası, GitHub kaynakları ve Windows 1.1.0 indirme bağlantıları içerir.

## Yerel önizleme

python -m http.server 8000

Ardından http://localhost:8000/ adresini açın.

## Yayın

Cloudflare Pages üzerinde onurcanorhan projesine kök klasör içeriği yayımlanır; derleme adımı gerekmez. Site EXE barındırmaz: indirmeler sushikiddo/komur GitHub Releases üzerinden sunulur.
