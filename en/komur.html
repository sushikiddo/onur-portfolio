DESKTOP APPLICATION / 1.1.0

Kömür

A desktop cat with Turkish chat, local AI, optional voice and everyday assistance.

Download for Windows · 1.1.0Source and READMESource ZIP

Windows 10/11 · x64 · 142 MB · No Python installation required

What does it do?

Kömür is my Python desktop companion project. Double-click the cat to chat, create notes and reminders, or request supported computer actions. Animations, sounds and reactions to supported media sessions accompany the character.

Chat and voice

Local chat through Ollama, with optional OpenAI and Claude providers. Manually started microphone input is transcribed locally; Windows Turkish speech can read responses.

Memory and reminders

Local SQLite history, notes and one-off or recurring reminders. Notifications require the application to be running.

Screen and PC assistance

Text and accessible controls from a selected window. Sensitive actions require confirmation; not every application or game is supported.

Games and media

Supported Steam/Riot launch paths and music/video reactions. Opening a client does not prove sign-in or a completed download.

Installation and use

  1. Download and run the per-user installer. An uninstaller is included.
  2. Optionally install local AI and voice models using the setup helper. Initial downloads need internet and additional storage.
  3. Double-click the cat, type a message and press Enter.
  4. Try Turkish commands such as “Not defterini aç”, “5 dakika sonra mola hatırlat” or “dans et”.
  5. Start and stop voice recording manually, then check the transcript before sending it.

The bundled guide recommends 16 GB RAM and approximately 4.7 GB of model download for the standard profile, or an approximately 2.6 GB lighter profile for 8 GB RAM. Voice recognition adds approximately 486 MB. Download sizes can change.

How it was developed

Python and Tkinter provide the desktop interface; Pillow handles drawing, pygame/Windows components handle sound, and SQLite stores memory. PyInstaller packages the executable and Inno Setup builds the installer. Character behavior, chat, providers, voice, screen assistance and distribution are separate modules.

AI tools assisted development. The source archive does not include a complete generation history, so file-level model attribution, human/AI contribution percentages and total development time cannot be verified. The GitHub README provides the module map and build/run instructions.

Checks and limitations

During publication preparation, 73 Python files passed syntax parsing and the installer extracted from Desktop.rar matched its accompanying SHA-256 checksum. The bundled historical report states 200 passed tests, one skipped test and 46 GUI scenarios; these are not newly rerun results. Complete end-to-end operation on a clean second computer was not checked here.

The installer is unsigned and Windows may show a publisher warning. Verify its hash against the published checksum.

Data and licensing

History and notes are stored locally. If a cloud provider is selected, active context may be sent to it; web searches also send search terms to an external service. The package excludes personal chats, API keys and downloaded AI models. No main project license is specified in the source archive; dependencies have separate licenses.
