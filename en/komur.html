What does it do?

Kömür is my Python project that brings a lifelike tuxedo cat onto both macOS and Windows desktops. Most of the time it rests peacefully and keeps you company: it glides to a corner when you watch movies, sways softly to music and stays quiet during games or meetings. It also hops onto window ledges, naps in a cardboard box, drinks milk and uses a scratching post.

Lifelike animation & desktop toys

4-beat walking, paw-and-cheek grooming, bow stretching, yawning, milk drinking, scratching post, cardboard box and tossable yarn ball rendered in lightweight stdlib Python vector art.

Memory, focus & weather

Notes and reminders stay local in SQLite. In Pomodoro mode the cat sleeps during focus blocks and stretches on breaks; optional weather displays a tiny icon over its head.

Quick HUD & commands

Right-click (two-finger click on macOS) opens a dark-glass Quick HUD with 1-click toys, window perching, mute toggle, control panel and quick Turkish command bar.

Real sounds & local awareness

Locally recognises video, music, games, coding, reading and idle time. Real cat audio plays only on petting, yawning and waking up, and can be muted in one click.

How to install and use

🍎 macOS

  1. Open Komur-2.4.0-macOS-arm64.dmg (or .zip) and drag Kömür.app into /Applications.
  2. If macOS shows an unsigned developer prompt on first launch, right-click Kömür.app → Open (or run xattr -dr com.apple.quarantine /Applications/Kömür.app).
  3. Single-click to pet, drag anywhere (drop near the MacBook notch to peek), or two-finger click for the Quick HUD.

🪟 Windows

  1. Download and run Komur-2.4.0-Windows-x64.exe directly.
  2. If SmartScreen appears, choose More info → Run anyway.
  3. Right-click opens the Quick HUD, middle-click opens the command bubble, and F1 opens the Control Panel.

Try commands such as “uyu”, “gerin”, “yuvarlan”, “not defterini aç”, “sesi %30 yap”, “5 dakika sonra mola hatırlat” or “hava nasıl”.

How it was built

Cross-platform Python and Tkinter desktop UI, procedural vector art and 4-beat feline locomotion (renderer.py, cat_poses.py, feline_locomotion.py), native AppKit/CoreImage/CoreGraphics/CoreAudio integration on macOS and user32/winsound/pygame on Windows, plus SQLite local storage. Both editions are packaged with PyInstaller.

Developed with help from AI tools. The module map and build steps for both operating systems are in the GitHub README.

Security, privacy & SHA-256

Window and media titles are never saved or sent online. Weather is off by default; when enabled, only your chosen city name is queried from Open-Meteo. Downloads contain no personal data, API keys or AI models.

Because the macOS and Windows binaries are not commercially code-signed, your OS may warn on first run. You can verify downloads with their SHA-256 checksums.
